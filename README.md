# NSS NIT Silchar — Interactive Brochure

A responsive physical-brochure unfolding experience built with HTML5, Tailwind CSS (CDN), GSAP and CSS 3D transforms.

## Run

Open `index.html` in a modern browser, or serve the folder with any static HTTP server.

## Controls
- Desktop: Left/Right arrow keys, mouse wheel, or floating arrows.
- Mobile: Swipe left/right or tap the arrows.
- The navigation loops infinitely between the cover and assembled brochure.

## Assets
All supplied brochure panels and composite reference spreads are stored in `assets/`.

Link to website: https://nss-orientation-webpage-8sms.vercel.app
